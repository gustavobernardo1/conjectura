## Statement as read from the primary source

Written before the proof was read. Source (verbatim in `STATE.md`): Conjecture 1.2 of Aalipour et al., arXiv:1507.02341: the normalized coefficients of the distance characteristic polynomial of any tree `T` with `n` vertices are unimodal with peak between `⌊n/2⌋` and `⌈n − n/√5⌉`. Unimodality (indeed log-concavity) is Theorem 2.1 of the source; only the location is open. Definitions: `D` the distance matrix, `δ_k` the coefficient of `x^k` in `det(D − xI)`, `d_k = 2^{k−(n−2)}|δ_k|`, `0 ≤ k ≤ n−2`; `ℓ_T(x) = −2^{−(n−2)} det(2xI − D)` has `[x^k]ℓ_T = d_k` for `0 ≤ k ≤ n − 2`. The project's reading of ties: **every** maximizing index lies in `[⌊n/2⌋, ⌈n − n/√5⌉]`. The upper half to be proved: for every tree of order `n ≥ 3`, every maximizing index `p` of `d_0, …, d_{n−2}` satisfies `p ≤ ⌈n − n/√5⌉`. The claim of the note is Theorem T9: `p < n − n/√5 + 3/5` for every maximizing index, hence `p ≤ ⌈n − n/√5⌉` (this implies the upper half under the strong tie reading, for every `n ≥ 3`). I checked that the claim is about this statement: same `d_k`, same index range `0..n−2`, every maximizing index, every tree of order `n ≥ 3`, same `M = ⌈n − n/√5⌉`. The note asserts more than needed (`p ≤ K = ⌈n − n/√5 − 2/5⌉ ≤ M`), which is a strengthening, not a change of the statement.
