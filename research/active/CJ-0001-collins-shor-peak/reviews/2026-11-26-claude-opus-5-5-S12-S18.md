## Statement as read from the sources (before reading the proofs)

Written down from `skeleton-locality.md` and `gamma-reduction.md` before the
proofs in the file under review were read.

- `S` is a tree on `s ≥ 2` vertices, `A ⊆ V`, `B = V ∖ A`, `a = |A|`, `t = |B|`.
  `r_A(x) = −2^{2−s} x det N_A(x)`, where
  `N_A = 2x I_B − P − 1_A1ᵀ − 1 1_Aᵀ − (a/2x)J` and `P` is the distance matrix.
  `r_A` is a polynomial of degree `≤ t + 1`.
- `L_B = L[B, B]`, `τ_v = 2 − g_v`, `z = L_B1 − τ_B`, `Φ_B = det(I + xL_B)`.
- `C_d`: the non-negative combinations of `x^e(1+x)^i` with `e + i ≤ d` and
  `2e + i ≥ d`. This equals the set of polynomials with a non-negative half-gamma
  expansion of degree `d`: the basis elements lie in `C_d`, and Lemma C gives
  the converse.
- Lemma F: `T` a tree on `j ≥ 1` vertices and `ν` a weight with values in
  `{0, 1, 2, …}`, **not identically zero**. Then `Φ(T, ν) ∈ C_j`.
- Property Γ⁺ for `S`: for every `A` with `|A| ≥ 1`, `r_A ∈ C_{s−|A|+1}`.
  Γ⁺ for every tree implies Conjecture Γ (MD-0010), which is the same
  statement restricted to `|A| ≥ 2`.
- New objects defined in the file: for a weighted tree `(T, ν)` on `j`
  vertices, `M = I + x(L_T + diag ν)`, `p_v = 1 + (2 − k_v − ν_v)x`,
  `V = pᵀ adj(M) p`, `R(T, ν) = (N + j − 1)(1 + x)Φ(T, ν) − V`, `N = Σν`.
  Γ_c: `R(T, ν) ∈ C_{j+1}` for every tree `T` on `j ≥ 1` vertices and every
  integer weight `ν ≥ 0`, `ν ≠ 0`.
