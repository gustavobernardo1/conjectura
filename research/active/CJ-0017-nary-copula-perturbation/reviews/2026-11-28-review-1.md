## Statement as read from the source

Definition 4.1 (as quoted): C:[0,1]^n -> [0,1] is an n-copula iff it is n-increasing (all box volumes >= 0) and (C2) C(x)=0 if some x_i=0, C(x)=x_i if x_j=1 for all j != i. Problem 4.1: C_1 = C - prod(x_i - C); is C_1 n-increasing / an n-copula; if not in general, characterise the C for which it is. The note proves only partial negative statements for C = Pi (product copula).

| (a) Definition / equivalence | Matches the quoted Definition 4.1. Equivalence for a polynomial satisfying (C2): density >= 0 on the cube implies all box volumes >= 0 (volume = integral of density); a negative density value at any point of [0,1]^n (including boundary points such as the corner (1,...,1)) gives, by continuity, a neighbourhood in the cube that contains a box of positive size with negative volume. Both directions hold. Values in [0,1] are implied: C = 0 on the faces x_i = 0, so C(x) = V([0,x]) = integral of density >= 0, and C(x) <= V([0,x_i] x [0,1]^(n-1)) = x_i <= 1. The note does not say this explicitly (minor omission, not an error). Boundary conditions of C_1^(n) and D_lambda verified (factor x_j - P vanishes when x_j = 0 or when all other coordinates are 1) and numerically for n = 3,4,5. |
