## Statement as read from the primary source

Recorded from the PDFs (chapter p. 202, p. 193; 2010 paper Problem 9.4)
before I read the note.

**Definitions (chapter, Defs 2.1, 2.4, 2.11, 3.1, 3.3; 2010 paper, Defs 2.1, 2.3, 2.4, 4.1).**

- *Fuzzy negation:* N non-increasing, N(0) = 1, N(1) = 0.
- *t-norm (t-conorm):* associative, commutative, non-decreasing, neutral
  element 1 (0).
- *Left-continuous t-norm:* left-continuous in each component (2010, Def 2.4(iii)).
- *Fuzzy implication:* (I1) non-increasing in x, (I2) non-decreasing in y,
  I(0,0) = I(1,1) = 1, I(1,0) = 0.
- *(S,N)-implication:* I(x,y) = S(N(x), y) for some t-conorm S and some fuzzy
  negation N. No continuity is required of either.
- *R-implication:* I_T(x,y) = sup{t ∈ [0,1] : T(x,t) ≤ y} for some t-norm T.
  No continuity is required.
- *QL-operation:* S(N(x), T(x,y)). It is a QL-implication iff it is a fuzzy
  implication.
- *Border-continuous:* "continuous on the boundary of the unit square, i.e. on
  [0,1]² \ ]0,1[²".
  - Read as "the restriction to the boundary is continuous", every t-norm would
    qualify, since its boundary values are 0, x and y. Then "non-border
    continuous t-norm" would be vacuous, and T_D, which generates the source's
    own exemplar I_WB, would not be non-border-continuous.
  - The only reading consistent with the problem and with Proposition 3.4
    (T border-continuous ⟺ I_T satisfies (OP)) is continuity of T, as a
    function on [0,1]², at every boundary point.
- *Weber implication (p. 184):* I_WB(x,y) = 1 if x < 1, and y if x = 1. This
  is I_TD (p. 189).
- *(OP):* I(x,y) = 1 ⟺ x ≤ y.

**Problem 4.2(i) (chapter, p. 202).** Does there exist a fuzzy implication
I ≠ I_WB such that:

- (a) there exist a t-conorm S and a fuzzy negation N with I = I_{S,N};
- (b) there exists a non-border-continuous t-norm T with I = I_T;
- (c) there is no left-continuous t-norm T′ with I = I_{T′}?

Clause (c) follows from (b): by Prop. 3.4, I fails (OP), and left-continuous
t-norms are border-continuous.

**Problem 4.8.1 of the monograph (chapter, p. 193).** Is
𝕀_{S,N} ∩ (𝕀_𝕋 \ 𝕀_{𝕋*}) = {I_WB}?

The chapter does not define 𝕀_{𝕋*}. In the 2008 survey (p. 1856), 𝕀_{𝕋*} is
"the family of all R-implications obtained from left-continuous t-norms having
strong induced negations", and 𝕀_{𝕋_LC} is the class of all left-continuous
t-norms. The survey also shows 𝕀_{S,N} ∩ 𝕀_{𝕋_LC} = 𝕀_{𝕋*}. So the set in
question is the same under either reading of 𝕀_{𝕋*}.

**Problem 4.5(ii) (chapter, p. 202) = Problem 9.4(ii) (2010).** Is I_WB the
only QL-implication that is also "an R-implication obtained from a non-left
continuous t-norm"? There are two readings:

- *Literal (L):* I = I_T for some non-left-continuous T.
- *Strong (S):* additionally, I is not the residual of any left-continuous
  t-norm, i.e. I ∈ 𝕀_QL ∩ (𝕀_𝕋 \ 𝕀_{𝕋_LC}).

The source does not say which reading it intends. See finding G2.

## Findings

### Hypotheses

The note puts no restriction on S, N or T beyond the source definitions. Its
examples use only objects allowed by the definitions:

- N_c is a fuzzy negation; it is discontinuous at 1.
- S_L and S*_c are t-conorms.
- T_c and T′_c are t-norms.
- T_M is a t-norm.

I looked for a hidden restriction in the sources (continuous N, strong N,
continuous or right-continuous S, the class 𝕀_{𝕋*}) and found none that the
problems intend.

- *Discontinuous N is allowed.* The exemplar I_WB itself has the discontinuous
  N_D2.
- *No restriction on S.* Problem 4.2 has none. The source's I_WB works with any
  S.

### Quantifiers

Each problem asks whether some I exists. The note exhibits explicit I_c and J_c
for every c ∈ ]1,2[, which matches the existential quantifier.

"Cannot be obtained as the residual of any other left-continuous t-norm" is
universal over t-norms. The note handles it with Lemma 4, which applies to
every T′ whose sections T′(x,·) are left-continuous at 1. That is correct and
covers all left-continuous T′.

### Logical implications

- Theorems A and B imply the "yes" answer to Problem 4.2(i). They give
  (S,N)-representations, non-border-continuous generating t-norms, Lemma 4 for
  clause (c), and distinctness from I_WB.
- They imply that the equality of Problem 4.8.1 is false. This holds under
  either reading of 𝕀_{𝕋*}.
- They imply the "no" answer to the first question of Problem 4.5(ii) under
  both readings L and S.
- The "continuum" part of the Corollary does not follow from what is proved
  (G1).
- **G2 (scope/interpretation).** Under reading L, Problem 4.5(ii)'s first
  question is already answered "no" inside the sources. This affects what the
  note can claim as its contribution:
  - The chapter (p. 189) presents the non-left-continuous t-norm
    T_{nM*}(x,y) = 0 if x+y < 1, min(x,y) otherwise, with residual I_FD.
  - The 2010 paper (Table 3 with right-continuous S_nM, Table 6, Prop. 6.4)
    shows I_FD = S_nM(1−x, min(x,y)) is a QL-implication.
  - So I_FD ≠ I_WB is a QL-implication that is the residual of a
    non-left-continuous t-norm.
  - I confirmed this by exact computation (see Reproduction).
  - The note's examples are non-trivial only under reading S, which the note
    does prove ("and of no left-continuous one"). The note does not say which
    reading it answers. It presents "the answer … is *no*" as if it settled the
    question, and does not mention that the sources already settle reading L.

  This does not invalidate the mathematics. It does invalidate any claim that
  the note is the first to answer Problem 4.5(ii) as literally worded.

### Dependency assumptions

The proofs use only the definitions, plus the facts that R-implications and
(S,N)-implications are fuzzy implications. Proposition 3.4 is not needed:
Lemma 4 replaces it.

- **G3 (unaddressed conflict with a published theorem).**
  - 2008 survey Theorem 6.5 (= 2010 paper Theorem 5.14), as printed: for a
    right-continuous t-conorm S and a t-norm T, I_{S,N_S} = I_T ⟺ (S, N_S, T)
    is a De Morgan triple, which requires N strict (survey Def. 2.19).
  - S*_c is right-continuous, and its natural negation is
    N_{S*_c}(x) = inf{t : S*_c(x,t) = 1} = N_c. I checked this by hand and by
    exact computation.
  - So J_c = I_{S*_c, N_{S*_c}} = I_{T′_c} with N_c not strict. Theorem B is
    therefore a counterexample to the theorem as printed.
  - This does not refute Theorem B. The printed theorem is already contradicted
    by the sources' own example: S_M is right-continuous with N_{S_M} = N_D2,
    and I_{S_M,N_D2} = I_WB = I_{T_D} (survey Remark 6.4(i)). So the theorem
    must carry an unstated hypothesis, presumably N_S strong, as in the 2010
    paper's family 𝕀_{S,N_S}.
  - The note does not mention this conflict. A reader comparing it with the
    sources will meet it, so it should be addressed.
- **G4 (attribution).**
  - Lemmas 1–2 and the general approach (lifting a t-subnorm and studying the
    residual of non-border-continuous t-norms) appear in EUSFLAT 2011 §4.
    That section has the lifting (5), the residual relation (6), and
    Theorem 4.5 characterising (EP) of I_T through the border-continuous
    projection M_T.
  - That paper is reference [20] of the chapter itself, cited right after
    Problem 4.1.
  - The note cites neither it nor Klement–Mesiar–Pap Cor. 1.8.
  - EUSFLAT 2011's example T_Z (non-border-continuous, residual with (EP)) is
    not an (S,N)-implication: its natural negation is constant 0.2 on [0.2,1[,
    but I_{T_Z}(x,y) depends on x there. So it does not pre-empt the note.
